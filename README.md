<h2 id="introduction">Introducción</h2>
<p>
  "Slenderman 2.0" es un juego de terror en primera persona inspirado en el infame mito de Slenderman. Los jugadores deben navegar por un bosque oscuro y tétrico para recolectar páginas mientras evitan la aterradora presencia de Slenderman.
</p>

<h2 id="features">Características</h2>
<ul>
  <li><strong>Atmósfera Inmersiva:</strong> Experimenta un ambiente oscuro y espeluznante con gráficos y sonido de alta calidad.</li>
  <li><strong>Jugabilidad Desafiante:</strong> Encuentra todas las páginas ocultas antes de que Slenderman te atrape.</li>
  <li><strong>Elementos Aleatorios:</strong> Cada partida es única con el comportamiento aleatorio de Slenderman.</li>
  <li><strong>Sistema de Persecución:</strong> Slenderman te persigue activamente cuando estás cerca.</li>
  <li><strong>Dificultad Progresiva:</strong> La agresividad de Slenderman aumenta con cada página recolectada.</li>
</ul>

<h2 id="how-to-play">Cómo Jugar</h2>
<ol>
  <li><strong>Objetivo:</strong> Encuentra todas las páginas dispersas por el bosque mientras evitas a Slenderman.</li>
  <li><strong>Movimiento:</strong> Usa las teclas <code>W</code>, <code>A</code>, <code>S</code>, <code>D</code> para moverte y <code>F</code> para encender la linterna.</li>
  <li><strong>Mirar Alrededor:</strong> Usa tu ratón para mirar alrededor.</li>
  <li><strong>Recolectar Páginas:</strong> Acércate a una página y presiona <code>E</code> para recolectarla.</li>
  <li><strong>Evitar a Slenderman:</strong> No mires a Slenderman por mucho tiempo; si se acerca demasiado, perderás.</li>
</ol>


<h2 id="controls">Controles</h2>
<ul>
  <li><code>W</code>: Mover Adelante</li>
  <li><code>A</code>: Mover a la Izquierda</li>
  <li><code>S</code>: Mover Atrás</li>
  <li><code>D</code>: Mover a la Derecha</li>
  <li><code>F</code>: Linterna</li>
  <li>Ratón: Mirar Alrededor</li>
  <li><code>E</code>: Interactuar/Recolectar Página</li>
  <li><code>Shift</code>: Correr</li>
  <li><code>Esc</code>: Pausa/Menú</li>
</ul>
